1. **Fase 1, inti alur:** login/register/lupa & reset sandi (state dasar), dashboard (unggah, antrean, riwayat), detail laporan audit (split pane, tab Ringkasan/Sumber/Diff).

3. **Fase 3:** bank korpus, billing, verifikasi sertifikat, konsol admin.
4. **Fase 4:** halaman galat sistem (400-503, offline), modal/toast, lalu varian mobile.
